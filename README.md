Cozy Study Bunny
A small, original browser-based study-pet prototype inspired by the general idea of studying for rewards.
Run it
Open `index.html` in a modern browser.
Choose a subject and session length.
Press Start studying. You can pause, resume, or reset.
Finish a session to earn coins.
Spend coins in the Bunny Shop and review your study stats.
Notes
This is a prototype, not the official Study Bunny app.
Progress is saved in the browser's local storage on that device/browser.
Clearing browser data can erase progress. It does not sync between devices.
For a real native iPhone app, this could be rebuilt with SwiftUI or wrapped as a progressive web app.
